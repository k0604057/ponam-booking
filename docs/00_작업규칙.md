# 포남동 예약관리 — 작업 규칙

상세 배경은 [`docs/01_프로젝트현황.md`](./01_프로젝트현황.md). 이 파일은 매번 밟는 함정만 짧게 적는다.

## 환경

- **단일 환경이다. 이 DB가 곧 운영이다.** 리허설할 dev가 없다.
- 스키마 변경은 `supabase/migrations/` 파일로만. 콘솔에서 테이블을 직접 고치지 않는다.
- 마이그레이션 파일명은 `<타임스탬프>_<이름>.sql`. 다른 형식은 CLI가 무시하고
  `db push` 가 아무것도 안 한 채 성공한 것처럼 끝난다. `supabase migration list` 로 먼저 확인.
- 마이그레이션은 **추가형 기본**. 변경형·파괴형은 `count` 로 영향 건수를 보고 → 컨펌 → 실행.
- Vercel은 웹 대시보드로 이미 연결돼 있다. **`vercel` CLI를 실행하지 않는다.**

## 보안 — 실제로 밟았던 것들

- **RLS는 행만 제한하고 컬럼은 제한하지 못한다.** 민감정보는 컬럼이 아니라 테이블로 분리한다
  (`reservation_private`, `reservation_finance`). "앱에서 가린다"는 방어가 아니다 —
  클라이언트가 `?select=` 로 아무 컬럼이나 지정할 수 있다.
- **`loading.tsx` 가 있는 라우트에서 페이지 안 `redirect()` 는 인가가 아니다.**
  스트리밍 SSR이라 스켈레톤이 200으로 먼저 나간다. 인가는 미들웨어에서 끝낸다.
- **새 테이블을 만들면 `enable row level security` 를 반드시 같이 쓴다.**
  권한은 default privileges로 자동으로 붙지만 RLS는 자동이 아니다.
- **새 함수를 만들면 `revoke all on function ... from public, anon;` 을 같이 쓴다.**
  `alter default privileges` 로는 PUBLIC EXECUTE를 없앨 수 없다. 함수마다 직접 회수한다.
  RLS 정책에서 쓰는 헬퍼는 `grant execute ... to authenticated` 도 잊지 말 것.
- 시크릿은 `~/.ponam.env`(600)에만. 채팅·코드·커밋·로그·에러 메시지에 남기지 않는다.
  `sync_runs.error_message` 는 owner/reservation이 읽으므로 마스킹한다.
- 초대 링크는 그 자체가 자격증명이다. 해시만 저장하고 로그에 찍지 않는다.
- service_role을 쓰는 라우트는 **쿠키 세션으로 권한을 먼저 확인**하고 그다음에 쓴다.

## 데이터

- `cleaning_tasks.scheduled_date` 는 퇴실일이고 크롤러·트리거가 관리한다. 사람이 정한 청소일은
  `planned_date`. 화면은 `coalesce(planned_date, scheduled_date)` 를 쓴다.
- 청소 담당(`cleaning`)은 `cleaning_tasks` 를 직접 UPDATE 할 수 없다.
  `claim_cleaning_task()` / `set_cleaning_done()` / `set_cleaning_planned_date()` RPC로만.
- 월별 집계는 `completed_at` 기준, **`Asia/Seoul` 로 변환해서** 센다.
  UTC로 세면 월말 밤 완료 건이 다음 달로 샌다.
- 크롤러는 **수집 0건이면 DB를 건드리지 않는다.** 이 안전장치를 없애지 마라. 실제로 403 차단을
  막아냈다.
- `sync_runs` 는 실패가 없어도 0행, 권한이 없어도 0행이다. 역할을 먼저 확인하고 판단한다.

## 화면

- **모바일 우선.** 폰 기준으로 설계하고 넓은 화면에서 늘린다. 표를 쓰지 않는다 —
  가로 스크롤이 생기면 진 것이다. 목록은 카드.
- 하단 탭 4개(청소/달력/예약/더보기), 아이콘+라벨, 56px + safe-area. 상단 햄버거 금지.
- 주요 버튼은 44px 이상, 화면 아래쪽. 사진은 `capture="environment"` 로 카메라 직행,
  업로드 전 리사이즈.
- 화면 문구는 한국어. 영어 에러 코드를 사용자에게 노출하지 않는다.
- 서로 의존하지 않는 쿼리는 `Promise.all`. 왕복 횟수가 곧 체감 속도다.

## 작업 방식

- Cowork(설계·스펙) → Claude Code(구현·검증·커밋·푸시).
- 스펙과 RLS가 어긋나면 **RLS가 옳다.** 어긋난 지점을 보고한다.
- 새 마이그레이션이 필요하면 만들기 전에 먼저 보고한다.
- 측정은 숫자로 보고한다. "빨라졌습니다"가 아니라 "320ms → 45ms".
